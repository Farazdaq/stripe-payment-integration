
#### The core/ folder in a React project is a place where you store the most essential and reusable parts of your application that everything depends on, such as API configuration, authentication logic, global utilities, app-wide settings, and state management; you should put something inside core/ when it is used across multiple features, is not tied to a single page or module, and represents foundational logic that must remain consistent throughout the entire app, like an API client, token handling, or shared helper functions, while anything that belongs to a specific feature, UI component, or is used only once should stay outside core/ in features/ or components/.
